 #begginerChallenge コード初心者です。自分で使いたいアプリをLeo AIに作ってもらい、１つのアプリに集めました。このアプリはすべて、Leo AIに教わりながら作っています。検索＆置換アプリ・色見本アプリはLeo AIに注文して作成してもらい、色や配置を少しアレンジしました。
 
 - 背景に流れ星を配置できるよう、htmlは背景を黒色に、bodyは透明にしました。html,bodyを一括で黒色にすると、星の背景が両者の間に挟まれるようで見えなくなったためです。
 - 背景の流星群は、ease-in-outで緩急をつけ、点滅もします。
 - 検索＆置換アプリは、主にスマホ用。
 - スワップゲームはフィッシャー・イェーツ法の完全ランダムを体感できるゲーム。矢印でつなげた絵文字、ボタンの柄、紐づく関数が、ボタンを押すたびに変わります。
 - 色見本アプリは、カラーピッカーかカラーコードで色を作り、好きなサイズでダウンロードできます。
 - PWA（Progressive Web App）化済み。
 - コード倉庫は、学んだコードを集めたもの。ボタン1つでコピーできます。色合いは変更済み。
 - XSS対策済み。
