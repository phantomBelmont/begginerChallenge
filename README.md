 #begginerChallenge コード初心者です。普段使いしたい各アプリをLeo AIに作ってもらい、メニュー画面に紐づけました。このアプリは、アレンジも含め、Leo AIに教わりながら作ったものです。
 
 - 背景に流れ星を配置できるよう、htmlは背景を黒色に、bodyは透明にしました。html,bodyを一括で黒色にすると、星の背景が両者の間に挟まれるようで見えなくなったためです。
 - 背景の流星群は、ease-in-outで緩急をつけ、点滅もします。
 - 検索＆置換アプリは、スマホ用に欲しくてLeo AIに作ってもらいました。目に優しいよう色味を変えたり、スペースを取らなくていい「検索する言葉」や「置換する言葉」は一列横並びに詰め込みました。使い勝手がいいよう、対象テキストを一番上に持ってきました。スマホのキーボード出現時も全画面が見えるよう、フレックスボックスにしました。
 - スワップゲームでは、フィッシャー・イェーツ法にて完全ランダムに、矢印でつなげた絵文字とボタンの柄、紐づく関数を変えられます。
 - 色見本アプリもLeo AIに作ってもらいました。カラーピッカーから選ぶかカラーコードを入力して色を作り、好きなサイズでダウンロードできます。全体の色味は少し変更。
 - PWA（Progressive Web App）化しました。
 - オフラインでも使えるよう、Service Workerを導入しています。
 - コード倉庫は、Leo AIに教わったアプリを組み込みました。全選択ボタンは省き、色も変更。学んだコードをボタン1つでコピーできるもの。
